# 雲嘉月報表系統

自動抓取固定的 Google 試算表「2026雲嘉眾召會每週人數報表」，依主日日期把週報歸到各月份，自選項目產生月報表。可安裝成 PWA。

## 運作方式

- 週報分頁名稱是主日日期（例如 `1004` = 10/4 主日，涵蓋 9/28 週一～10/4 週日）。月份依主日日期歸屬：主日落在幾月，那一週就算幾月。
- 年份取自每個分頁 L2 儲存格（週日日期），取不到才用今年。
- 讀取每個分頁「顯示區」（A～W 召會生活、Y～AW 青年人／兒童）第 5 列起各小區的數字，遇到「雲嘉總計」那列停止；「小計」列不讀，改由系統自己加總。
- 主日總數為 0 的週視為還沒填資料，不納入計算。

## 計算規則

| 項目類型 | 月報數字 |
|---|---|
| 一般人數（主日、禱告、小排…） | 當月有資料各週的平均 |
| 基數、名冊、受浸目標、受浸累計、兒童排數、得少人數 | 當月最後一週的數字（基數、受浸目標、兒童排數、得少人數只顯示一欄，取最新一週） |
| 本月受浸 | 本月底累計 − 上月底累計 |
| 家聚會 | 出訪 + 受訪 |
| 國中、高中、得少（小學／國中／高中）細分 | 讀自週報的「數據輸入區」（AY 欄起），依小區名稱對應 |
| 佔基數比 | 數字 ÷ 對應基數 |

- 小區有缺週（顯示「缺」）時，只平均有回報的週，名稱旁會標示「（3/4 週）」。
- 大區小計、雲嘉總計 = 各小區月數字加總。

## 功能

- **報表設定**：選月份（可多選，同一張表先列完一個月的全部項目再接下個月；基數放最前面只顯示一次）、顯示佔比、較上月增減（基數、受浸目標不顯示增減）。
- **項目**：上方列出已選項目（按 × 移除）；按「編輯項目」打開挑選面板，分成召會生活、受浸、青年人、得少、兒童五頁，青年人與得少用「對象 × 項目」方格勾選，點列名或欄名可整列／整欄勾選。按「調整順序」可用 ‹ › 移動項目，報表與 Excel 的欄位順序照這個排列。
- **範本**：沒有內建範本，全部自訂，存在雲端（Cloudflare D1）所有人共用；資料庫未設定時退回存在該裝置。設定好項目、順序、顯示選項後按「存成新範本」；之後可「用目前設定更新此範本」、改名、刪除，設定跟範本不同時會提示「尚未存入」。回到網頁分頁時會重新讀取，看得到別人剛存的範本。
- **表頭分類**：各種基數（全召會、青職、大專、國高中、兒童）統一放在最前面的「基數」底下；青職、大專、國高中（基數、主日、家聚、排聚）、國中、高中（主日、家聚、出訪、受訪、排聚）、兒童主日（名冊、基數、主日）、兒童排（排數、兒童全部、福音兒童、大人全部、福音家長）、得少（人數、主日、受訪及細分）在表頭多一層分類，同分類的項目自動排在一起。
- **下載 Excel**。
- **上傳檔案**：抓不到試算表時，可以手動上傳下載下來的 .xlsx。
- 上次抓到的資料會暫存在瀏覽器，開啟時先顯示，再背景更新。

## 試算表設定

試算表的共用設定必須是「知道連結的任何人」→「檢視者」。伺服器（Cloudflare Pages Function `functions/api/sheet.js`）用匯出網址抓 .xlsx，快取 5 分鐘；按「重新抓取」會略過快取。

要換別份試算表：在 Cloudflare Pages 專案的「設定 → 環境變數」加 `SHEET_ID`，或修改 `functions/api/sheet.js` 的 `DEFAULT_SHEET_ID`。

試算表的分頁格式（欄位位置）如果改了，要同步修改 `js/report.js` 的 `FIELDS`。

## 部署到 Cloudflare Pages

1. Cloudflare 後台 → Workers & Pages → 建立 → **Pages** → 連接 Git，選這個 repo，分支 `main`。
2. 建置設定：Framework preset 選 None，建置指令留空，輸出目錄填 `/`。
3. 部署完成後打開網址即可。

### 共用範本（D1 資料庫）

1. Cloudflare 後台 → 儲存空間與資料庫 → D1 → 建立資料庫，名稱例如 `all-yc-db`。
2. Pages 專案 all-yc → 設定 → 繫結（Bindings）→ 新增 → D1 資料庫：變數名稱填 `DB`，選剛建立的資料庫。
3. 重新部署一次（部署 → 最新那筆 → 重試部署）。
4. 資料表 `yc_presets` 會在第一次使用時自動建立，不用另外跑 SQL。

沒設定資料庫時網站照常運作，範本只會存在各自的裝置，範本區下方會顯示「共用範本尚未啟用」。

範本沒有密碼保護，知道網址的人都能新增、修改、刪除範本。

本機測試：

```bash
npm install
npx wrangler pages dev . --d1 DB=local-db   # http://localhost:8788
```

## 目錄結構

```
index.html               主頁面
css/style.css            樣式（含深色模式）
js/report.js             解析週報、歸月、計算月報（純函式）
js/app.js                畫面、設定、範本、匯出
js/xlsx.core.min.js      SheetJS（Apache-2.0，見 vendor/xlsx/LICENSE）
functions/api/sheet.js   GET /api/sheet：代抓 Google 試算表
functions/api/presets/   共用範本 API（GET 列表、PUT 存檔、PATCH 改名、DELETE 刪除）
manifest.json, sw.js     PWA
```
