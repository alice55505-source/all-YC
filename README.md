# 雲嘉月報表系統

抓取固定的 Google 試算表（每週人數報表），依主日日期歸月，產生月報表。

## 特殊規則

- 分頁名稱 = 主日日期（`1004` = 10/4 主日，涵蓋 9/28～10/4），月份依主日歸屬。
- 主日總數為 0 的週視為未填，不計算；小區缺週只平均有回報的週。
- 基數、受浸目標、排數、兒童排數、得少人數：只顯示一欄，取最新一週（或「統計到」那週）。
- 本月受浸 = 本月底累計 − 上月底累計。
- 青職／大專家聚出訪受訪、國中、高中、得少細分讀自「數據輸入區」（AY 欄起），依小區名稱對應。
- 試算表欄位位置改了，要同步改 `js/report.js` 的 `FIELDS`。

## 部署（Cloudflare Pages）

1. Workers & Pages → 建立 → **Pages** → 連接 Git，選此 repo、分支 `main`，建置指令留空，輸出目錄 `/`。
2. 試算表共用設定：知道連結的任何人可檢視。
3. 共用範本：D1 建立資料庫 → Pages 專案「設定 → 繫結」新增 D1，變數名稱 `DB` → 重試部署。資料表自動建立。未設定時範本只存在各自裝置。

換試算表：Pages 環境變數 `SHEET_ID`，或改 `functions/api/sheet.js`。

本機：`npx wrangler pages dev . --d1 DB=local-db`
